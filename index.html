How to Use the Simulation

The Dining Philosophers Problem is a foundational synchronization problem formulated by Edsger Dijkstra in 1965 to illustrate resource allocation challenges and deadlock.

  1. Start Simulation: Click the white START button to activate the table.
  2. Manual Action: Under the Manual Step Actions card, click any philosopher button:
    • Step 1: Thinking → Hungry (Attempts to acquire first chopstick).
    • Step 2: Hungry (holds 1 fork) → Acquires second chopstick if available.
    • Step 3: Transition to Eating → Releases both forks and returns to Thinking.
  3. Triggering a Deadlock: In Naive Mode, make all philosophers hungry sequentially. Each will grab their left chopstick simultaneously, causing a circular wait deadlock.
  4. Asymmetric Solution: Select Asymmetric Mode where philosopher PN-1 picks up their right fork first, effectively breaking the circular dependency and preventing deadlock!
  5. Auto Mode: Press AUTO to let the philosophers dynamically decide when to think, get hungry, and eat.

Algorithm & Components Breakdown

Key Invariant: To eat, a philosopher requires both adjacent chopsticks simultaneously.

Code Operations:

  • THINKING(): The thread executes independent work without needing shared resources.
  • Wait(chopstick): Decrements semaphore (P operation). If the fork is held (semaphore = 0), the philosopher blocks until it becomes available.
  • EATING(): Critical section. Accessing shared plate using both mutual exclusion resources.
  • Signal(chopstick): Increments semaphore (V operation), releasing resource ownership so adjacent neighbors can dine.

Deadlock Conditions Illustrated:

  • Mutual Exclusion: Chopsticks cannot be shared.
  • Hold and Wait: Holding one chopstick while waiting for another.
  • No Preemption: Chopsticks cannot be forcibly taken.
  • Circular Wait: P0 waits for P1, P1 waits for P2... PN-1 waits for P0.
